# HNG — Stage 0 Task: Profile Card

A responsive, accessible profile card built with semantic HTML, CSS, and vanilla JavaScript.

## 🧩 Features
- Fully semantic markup (article, header, section, nav, figure)
- Accessible and keyboard-friendly
- Responsive layout (mobile, tablet, desktop)
- Live current time in milliseconds (updates every second)
- Includes all required `data-testid` attributes for automated testing

## 🗂️ Structure
```
index.html
style.css
script.js
```

## 🧪 How to Run
1. Clone the repo:
   ```bash
   git clone https://github.com/yourusername/HNG-stage_0-profile-card.git
   ```
2. Open `index.html` directly in your browser — no build step needed.
